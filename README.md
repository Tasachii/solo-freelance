# ติวได้ตังค์ — Tutor Admin (Demo)

เดโมกดเล่นได้ของระบบหลังบ้านสำหรับ **ติวเตอร์เดี่ยว** ที่มีนักเรียน 30–80 คน
สร้างเพื่อใช้ตอน pitch และส่งให้ติวเตอร์จริงลองกดตอนสัมภาษณ์ validation

**🔗 เปิดเดโม:** https://tasachii.github.io/tutordai-demo/

> เดโม · ข้อมูลสมมติทั้งหมด — ไม่มี backend ไม่มีการเก็บข้อมูลจริง
> ข้อมูลที่กดเล่นถูกเก็บไว้ใน localStorage ของเครื่องผู้ใช้เท่านั้น

---

## ปัญหาที่ระบบนี้แก้

ทุกสิ้นเดือน ติวเตอร์อิสระเสียเวลา **5–10 ชั่วโมง** ไปกับการนั่งนับครั้งเรียน
คิดเงิน ส่งข้อความหาผู้ปกครองทีละคน เช็คสลิปทีละใบ และทวงคนค้างแบบเกรงใจ
บางครั้งลืมนับครั้งเรียน = สอนฟรี

Flow ของระบบ:

```
เช็คชื่อแตะเดียวทุกคาบ
   → สิ้นเดือนระบบคิดเงินอัตโนมัติจากครั้งที่สอนจริง
   → ส่งบิลเข้า LINE ผู้ปกครอง พร้อม QR PromptPay ของติวเตอร์เอง
   → ผู้ปกครองแนบสลิป ระบบตรวจให้
   → dashboard เห็นชัดว่าใครจ่าย ใครค้าง
   → ระบบทวงแทนแบบสุภาพ
```

## จุดยืนของผลิตภัณฑ์

| จุดยืน | เหตุผล |
| --- | --- |
| ระบบ **ไม่แตะเงิน** | ผู้ปกครองโอนตรงเข้าบัญชีติวเตอร์ ระบบแค่ตรวจสลิปและบันทึก — เลี่ยงประเด็นใบอนุญาต e-Money ของ ธปท. |
| คนทวงคือ **ระบบ** ไม่ใช่ติวเตอร์ | ความสัมพันธ์กับผู้ปกครองไม่เสีย ติวเตอร์ไม่ต้องเกรงใจจนไม่กล้าทวง |
| หน้าเช็คชื่อคือ **หน้ากันเงินรั่ว** | ลืมเช็คชื่อ 1 ครั้ง = สอนฟรี 400 บาท |

## หน้าจอในเดโม

| หน้า | ทำอะไรได้ |
| --- | --- |
| Landing | อธิบายผลิตภัณฑ์ กดเข้าเดโม |
| วันนี้ | เช็คชื่อรายคาบ / บันทึกนักเรียนลา (ไม่นับเงิน เก็บเป็นคาบชดเชย) |
| นักเรียน | ดูโปรไฟล์ ประวัติเรียน และส่งสรุปพัฒนาการให้ผู้ปกครอง |
| บิลสิ้นเดือน | ดูยอดรวม/เข้าแล้ว/ค้าง · ตรวจสลิป · ให้ระบบทวงแทน · ส่งบิลเข้า LINE ทุกคน |

## หนึ่งโค้ดเบส สองบริบทการใช้งาน

ระบบนี้ไม่ได้แยกเป็น "เว็บ dashboard" กับ "แอพมือถือ" คนละตัว เพราะติวเตอร์คนเดียวกัน
ใช้งานสองจังหวะที่ต่างกัน และผู้ปกครองไม่เคยเข้าแอพเลย — เขาอยู่บน LINE

| จอ | บริบท | หน้าตา |
| --- | --- | --- |
| < 900px | ระหว่างคาบ ยืนอยู่ ต้องเร็ว | แอพมือถือเต็มจอ แท็บล่าง หน้าเช็คชื่อเป็นพระเอก |
| ≥ 900px | นั่งโต๊ะ ปิดบิลสิ้นเดือน | โต๊ะทำงาน: sidebar ซ้าย ตารางกว้างเห็นทุกคนพร้อมกัน |

แดชบอร์ดบนเดสก์ท็อปจงใจมีแค่ **สามตัวเลข** (ค่าเรียนเดือนนี้ / เข้าแล้ว / ยังไม่เข้าบัญชี)
ติวเตอร์เดี่ยวที่มีนักเรียน 40 คนไม่ต้องการกราฟ retention — กราฟพวกนั้นเป็นฟีเจอร์ของสถาบัน

ติดตั้งเป็นแอปบนโฮมสกรีนได้ (PWA) และเปิดได้ตอนเน็ตหลุด

ยอดเงินทุกจุด **คำนวณสดจาก state** — กดเช็คชื่อในแท็บ "วันนี้"
แล้วยอดในแท็บ "บิลสิ้นเดือน" จะขยับตามทันที



## Stack

- Vite + React 18, plain CSS (ไม่ใช้ UI library และไม่ใช้ Tailwind)
- State เป็น React state ล้วน persist ลง `localStorage` key `tutordai-demo-v1`
- HashRouter เขียนเอง เพราะ GitHub Pages ไม่มี SPA fallback
- Font: Anuphan (Google Fonts) แบบ self-host — ตัด render-blocking request ข้าม origin
  Anuphan เป็น variable font ไฟล์เดียวครอบคลุมน้ำหนัก 400–700 เก็บเฉพาะ subset thai + latin
- PWA: manifest + service worker (หน้าเว็บเอาของใหม่ก่อนเสมอ กันเดโมค้างเวอร์ชันเก่า)
- ไม่มี backend, ไม่มี API จริง, ไม่มี analytics, ไม่มีระบบ login

## ระบบสี

ยืมระบบ **"washi tea-house"** มาจาก [Open Gambit](https://opengambit.org) ของทีมเดียวกัน:
กระดาษสาโทนครีมอุ่นในโหมดสว่าง ถ่านไม้อุ่นในโหมดมืด — ไม่มีขาวจ้า ไม่มีดำเย็น
ทุกพื้นผิวอุ่นหมด ใช้เส้นขอบบางแทนเงาหนา

สีแบรนด์จากบรีฟเดิม (เขียวเข้ม `#123B2E` / ส้มอิฐ `#E4572E` / ทอง `#FFD36B`) ยังอยู่ครบ
เปลี่ยนเฉพาะ *พื้นผิว* ให้อุ่นขึ้นและเพิ่มโหมดมืด

ธีมเริ่มต้นตามระบบปฏิบัติการ กดสลับเองได้ และจำค่าไว้ใน `localStorage`

## Deploy

Push ขึ้น `main` แล้ว GitHub Actions จะ build ด้วย Node 20 และ deploy ไป GitHub Pages
ให้อัตโนมัติ (`.github/workflows/deploy.yml`) โดยตั้ง Pages source = GitHub Actions

`vite.config.js` ตั้ง `base: '/tutordai-demo/'` ให้ตรงกับชื่อ repo — ถ้าเปลี่ยนชื่อ repo
ต้องแก้ค่านี้ตาม ไม่งั้น asset จะ 404

## ข้อจำกัดที่ตั้งใจให้เป็น

เดโมนี้ **ไม่ใช่ระบบ production** — ไม่มีการยืนยันตัวตน ไม่ได้ต่อ payment gateway จริง
สลิปและ QR เป็นภาพจำลอง และข้อมูลนักเรียนทั้งหมดเป็นข้อมูลสมมติ
