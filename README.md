# Solo Freelance

แอดมินให้คนที่ทำงานคนเดียว — ฟรีแลนซ์ทุกอาชีพที่รับงานเอง เก็บเงินเอง ตอบแชทเอง
ติวเตอร์คืออาชีพแรกที่เปิดใช้ อาชีพอื่นใช้เอนจินเดียวกัน — เดโมแบบ static ไม่มีหลังบ้าน ไม่มีล็อกอิน ไม่มีการจ่ายเงินจริง

เดโม: https://tasachii.github.io/solo-freelance/

---

## หลักการที่ห้ามละเมิด

1. **Solo ไม่ถือเงินของใคร** — สร้าง QR ของผู้ให้บริการเอง ตรวจสลิป ออกใบเสร็จ เงินเข้าบัญชีเจ้าของงานโดยตรง
2. **ตัวเลขทุกตัวมาจาก ledger** — ไม่มีค่าคงที่ ไม่มีเทมเพลตหรือ AI คำนวณเงินเอง
3. **AI ร่าง คนกดส่ง** — ไม่มีข้อความไหนออกไปโดยผู้ใช้ไม่ได้กดปุ่ม "ส่ง"
4. **`core/` กับ `app/` ไม่รู้จักอาชีพ** — คำเฉพาะอาชีพอยู่ใน `professions/` และ `copy/` เท่านั้น
5. **ข้อความถึงลูกค้าเป็นเสียงของผู้ให้บริการ** — ห้ามมีคำว่า "ระบบ" "อัตโนมัติ" หรือ "Solo" (ยกเว้นบรรทัดเล็กท้ายใบเสร็จ)

## โครงสร้าง

```
src/
  core/         engine — ledger, billing, messages, faq, selectors, export
                ไม่มีคำเฉพาะอาชีพ ไม่มี React นอกจาก store.tsx
  app/          จอของผู้ให้บริการ + จอฝั่งลูกค้า (ClientPreview, Receipt)
  platform/     หน้าขาย — Landing, Pricing, WaitlistSheet
  professions/  นิยามอาชีพ: vocab, การคิดเงิน, กฎ FAQ
  copy/         ข้อความทั้งหมด — คอมโพเนนต์ห้ามพิมพ์ string เอง
  mock/         seed สำหรับชุดข้อมูลเดโม
```

### เพิ่มอาชีพใหม่

แตะแค่ `src/professions/`:

1. สร้าง `src/professions/<id>.ts` ที่ export `ProfessionTemplate`
2. ใส่ในลิสต์ใน `src/professions/index.ts`

เท่านั้น — อาชีพใหม่จะขึ้นในตัวเลือกและในตาราง "Engine เดียว ทุกอาชีพ" บนหน้าแรกเอง
โดยไม่ต้องแก้ `core/`, `app/` หรือ `platform/` แม้แต่บรรทัดเดียว

## รัน

```bash
npm install
npm run dev
```

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | เซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | `tsc` แล้ว build ลง `dist/` |
| `npm run preview` | เสิร์ฟ `dist/` ที่ build แล้ว |

### พารามิเตอร์สำหรับเดโม

อยู่ใน hash ได้ (HashRouter) หรือใน query ปกติก็ได้:

- `?scenario=package-heavy` — เลือกชุดข้อมูล: `default`, `package-heavy`, `monthly-heavy`, `empty`

## หมายเหตุทางเทคนิค

- **HashRouter** เพราะ GitHub Pages ไม่มี SPA fallback
- **วันที่** เก็บเป็น ISO ค.ศ. แสดงผลเป็น พ.ศ. คำนวณด้วย `Date.UTC` ทั้งหมดจึงไม่ผูกกับ timezone
- **สถานะ** เก็บใน `localStorage` คีย์ `solo-demo-v3` · schema 4 มี migration จาก 3 ที่ไม่ทำข้อมูลหาย
- **โหมดใช้จริง** เมนู → เริ่มใช้จริง = ล้างข้อมูลสมมติ เดินวันตามเครื่อง ตรวจสลิปเองไม่สุ่ม
- **สำรองข้อมูล** เมนู → สำรองข้อมูล ได้ไฟล์ JSON กู้คืนได้ · เตือนเมื่อทิ้งช่วงเกิน 7 วัน
- **ขนาดจอ** เมนู → ขนาดจอ · `จอฉาย` ขยายทั้งตัวอักษรและความกว้างสำหรับฉายตอนพรีเซนต์
- **ส่งข้อความ** ผ่าน LINE share link ออกจากบัญชีของผู้ใช้เอง ไม่ใช่บอท และนับว่าส่งเมื่อผู้ใช้ยืนยัน
- **สี** อยู่ใน CSS custom properties ที่หัวไฟล์ `src/index.css` เท่านั้น มีธีมสว่าง/มืด/ตามเครื่อง
- **CSV** ใส่ BOM ให้ Excel ไทยอ่านออก และเรียงตามวันที่จริงไม่ใช่สตริงที่ format แล้ว
- **ไม่มี UI library** ใช้ CSS ล้วน dependency มีแค่ `react`, `react-dom`, `react-router-dom`

## ฟอร์มลงชื่อ

`WAITLIST_ENDPOINT` ใน `src/platform/config.ts` ว่างไว้ = ข้อมูลถูก log ลง console เท่านั้น
ไม่ถูกส่งออกไปไหน ใส่ URL ของ Google Form `formResponse` และแก้ `WAITLIST_FIELDS`
ให้ตรงกับ entry id จริงเมื่อพร้อมเก็บข้อมูล
